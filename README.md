# Khan's Cafe

A responsive cafe landing page built with Tailwind CSS for learning and practice purposes.

## Preview

Khan's Cafe is a frontend project designed to practice modern web design concepts using Tailwind CSS. The website includes a clean layout with multiple sections commonly used in real-world landing pages.

## Tech Stack

- HTML5
- Tailwind CSS

## Features
- Responsive Design
- Modern UI Layout
- Hero Section
- Coffee Menu Section
- Statistics Section
- Footer Section

## What I Practiced

- Tailwind CSS Utility Classes
- Flexbox
- CSS Grid
- Responsive Breakpoints
- Margin & Padding Utilities
- Typography
- Layout Design

## Purpose

This project was created only to improve my Tailwind CSS and frontend development skills.
