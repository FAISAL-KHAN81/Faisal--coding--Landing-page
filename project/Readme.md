# Responsive Landing Page

A modern and fully responsive landing page built using HTML and CSS. This project was created as part of my CSS learning journey to practice layouts, styling, responsiveness, and modern web design techniques.

## Features

* Responsive design for mobile, tablet, and desktop devices
* Clean and modern user interface
* Flexbox and CSS positioning
* Custom typography and styling
* Smooth layout adaptation using media queries
* Semantic HTML structure

## Technologies Used

* HTML5
* CSS3

## What I Learned

Through this project, I practiced:

* CSS Flexbox
* Responsive Web Design
* Media Queries
* CSS Positioning
* Typography and Spacing
* Image Handling
* Layout Structuring
* Mobile-First Design Principles

## Project Goal

The main goal of this project was to strengthen my understanding of CSS and learn how to create responsive websites that work well across different screen sizes.
